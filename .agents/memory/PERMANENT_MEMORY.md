### چکیده قوانین بنیادین و حافظه دائمی:
1. **پروژه:** مینادنت (MinaDent) — سامانه جامع مدیریت کلینیک دندانپزشکی، کاملاً فارسی، آفلاین‌اول، ۱۰۰٪ منطبق با iOS 27 Fluid UX.
2. **آمار آزمون‌های فعال:** ۱۰۵ سوئیت آزمون · ۱,۵۳۲ تست Vitest پاس‌شده (۱۰۰٪) · صفر خطای تایپ‌اسکریپت · بیلد پایدار پروداکشن.
3. **قوانین و ممنوعیات قطعی:**
   - حذف فیزیکی ممنوع (فقط Soft-Delete).
   - هیچ دکمه یا کامپوننت ساختگی مجاز نیست (Zero Placeholders).
   - اسکرول افقی ناخواسته ممنوع (`overflow-x: clip` و معماری تک‌اسکرول).
   - تاچ‌تارگت‌ها حداقل ۴۸ پیکسل برای استفاده با دستکش جراحی.
   - فرمول قطعی سهم پزشک: کسر لابراتوار و ایمپلنت قبل از محاسبه درصد.
   - تبدیل تمامی اعداد به ارقام فارسی (`toPersianDigits`).
4. **نسخه‌بندی خودکار:** با هر ویرایش، نسخه پروژه با `npm run bump` ارتقا می‌یابد.
5. **پایداری آفلاین:** کارکرد ۱۰۰٪ با Dexie IndexedDB بدون نیاز به اینترنت، و همگام‌سازی لحظه‌ای با BroadcastChannel و Supabase.
