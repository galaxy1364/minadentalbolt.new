# MinaDent Enterprise Coding & Verification Rules

## 1. Zero Placeholders & Zero Broken Actions
- Every button, input, toggle, select, and modal trigger must perform a concrete state update, data mutation, or display an informative modal/dialog.
- No dummy `onClick={() => {}}` or mock data passes.

## 2. Living Animated Gemini Mesh Background
- Dynamic ambient fluid motion reflecting the active module theme (`--module-color`, `--module-gradient-from`, `--module-gradient-to`).
- Smooth color interpolation across route changes.
- High contrast against all text and card surfaces in both Light Mode and Dark Mode (OLED pitch black).

## 3. ISO 27001 Clinical Security & Immutable Auditing
- Every medical/financial change is logged through `recordAuditLog()` (`useAuditLog.ts` / `auditLogger.ts`).
- Absolute prohibition of physical records deletion; only soft-deletion (`deleted_at`).
- Role-Based Access Control (`canAccess()`).

## 4. Dental Standards Compliance
- Dual FDI (11–48 / 51–85) and Palmer notation (1–8 / A–E with bracket glyphs).
- Full 6-point periodontal depth recording (PPD/BOP).
- ITI dental implant tracking with hardware passport.
- 100% Persian digits and Jalali calendar conversion.
